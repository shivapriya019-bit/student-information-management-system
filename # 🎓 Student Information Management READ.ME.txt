# 🎓 Student Information Management System

Student Information Management System is a web-based application developed using Python, Django, HTML, CSS, and MySQL. The application provides a secure admin login for managing student records. After authentication, the administrator can perform complete CRUD (Create, Read, Update, Delete) operations, upload student profile images, and view detailed student information. The project demonstrates Django authentication, Models, Forms, URL Routing, Templates, Static and Media Files, and MySQL database integration.
 📌 Features

-## ✨ Features

- 🔐 Secure Admin Login
- ➕ Add Student Records
- 📋 View Student List
- 👤 View Student Details
- ✏️ Update Student Information
- 🗑️ Delete Student Records
- 🖼️ Upload Student Profile Pictures
- ✔️ Form Validation
- 🗄️ MySQL Database Integration
- ⚙️ Django ORM for Database Operations
- 📁 Static and Media File Handling
- 🎨 User-Friendly Interface
- 🌐 Django URL Routing and Templates

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/student-management-system-django.git
```

### 2. Move to the project directory

```bash
cd student-management-system-django
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Apply migrations

```bash
python manage.py migrate
```

### 5. Start the development server

```bash
python manage.py runserver
```

### 6. Open in your browser

```
http://127.0.0.1:8000/
```

## 📖 Project Workflow

- Users can add new student information through a Django form.
- Student records are stored in the SQLite database.
- Users can view all students in a list.
- Individual student details can be viewed.
- Existing records can be updated or deleted.
- Student profile pictures are uploaded and displayed using Django Media Files.
